## Add RMScopies: Raaphorst–Moura–Stevens strength-3 CAs, extended by shifted column copies

This PR adds `RMScopies(q, m)`, `RMScopiesCA(k, v)`, `N_RMScopiesCA(t, k, v)` and the data frame `RMScopies_tested` (new file `R/RMScopies.R`, help page `man/RMScopies.Rd`, tests `tests/testthat/test-RMScopies.R`, four exports in `NAMESPACE`).

**What it does**
- `m = 0`: the Raaphorst–Moura–Stevens (2014) array CA(2q³−1; 3, q²+q+1, q) for prime powers q (GF arithmetic via `lhs::create_galois_field`, as elsewhere in the package). As far as I can tell, this construction was not yet implemented in the package.
- `m ≥ 1`: adds m columns that are shifted copies of existing columns (copy in the zero row and the first block, +1 in the second block), plus layers of q² runs built from the q+1 mutually orthogonal directions of PG(1,q), plus one correction run.

**Limited to tested parameters**
- `RMScopies_tested` lists the 328 combinations (q, m) whose arrays, as produced by this R code, were verified exhaustively:
  - q = 3, 4, 5, 7, 8, 9: all m;
  - q = 11: m = 0–13 and 22; q = 13: m = 0–14; q = 16: m = 0, 1, 16;
  - q = 19: m = 1, 19, 20.
- 325 of them were checked with `ca_verify.c` from caverify's ca-tools repository. For q = 19, the R output coincides with arrays verified by an independent brute-force checker.
- `RMScopiesCA` and `N_RMScopiesCA` only use these combinations. For k columns they take the smallest tested m′ ≥ k − (q²+q+1) and drop columns. All 78 improved entries are covered.
- `RMScopies(q, m, tested_only = FALSE)` builds other combinations, e.g. as examples or counterexamples for the proof. Such arrays should be verified with `ca_verify`.

**Run sizes**
- m = 0: 2q³ − 1
- m = 1: 2q³ − 1 + q²(q − 2)
- m ≥ 2: 2q³ + q²·max(q − 2, ⌈m(q − 2)/q⌉)

**Effect on the tables (Nov 2024 status in ColbournTables.md)**
78 entries are improved, for example:
- CA(324;3,32,5) instead of 349; CA(325;3,36,5) instead of 349; CA(350;3,37,5) instead of 365
- CA(930;3,58,7) instead of 979; CA(931;3,64,7) instead of 1014
- CA(1408;3,81,8) instead of 1455; CA(2025;3,100,9) instead of 2169
- CA(3751;3,144,11) instead of 3971; CA(6253;3,196,13) instead of 6565
- q = 19: k = 382–401

There is no improvement for q = 3, 4, 16, 17, 23 or 25.

**Testing**
- The tests use `caverify::ca_verify` like the other test files. Locally, I ran them with a brute-force stand-in for `ca_verify`, since I could not install the full dependency set: 81 expectations pass.
- All arrays were additionally checked by independent brute-force checkers (Python and C), including q = 4, 7, 8, 9, 11, 13, 16 and 19.
- For q = 4, 5, 7, 8, 9 the R arrays coincide (up to row order) with those of the separate Python implementation in the repository above.
- `man/RMScopies.Rd` was generated by roxygen2 from the file alone. Please re-run `devtools::document()` if needed.
