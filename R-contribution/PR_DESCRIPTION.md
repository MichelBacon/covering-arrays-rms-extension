## Add RMScopies: Raaphorst–Moura–Stevens strength-3 CAs, extended by shifted column copies

This PR adds `RMScopies(q, m)`, `RMScopiesCA(k, v)` and `N_RMScopiesCA(t, k, v)` (new file `R/RMScopies.R`, help page `man/RMScopies.Rd`, tests `tests/testthat/test-RMScopies.R`, three exports in `NAMESPACE`).

**What it does**
- `m = 0`: the Raaphorst–Moura–Stevens (2014) array CA(2q³−1; 3, q²+q+1, q) for prime q. As far as I can tell, this construction was not yet implemented in the package.
- `m ≥ 1`: adds m columns that are shifted copies of existing columns (copy in the zero row and the first block, +1 in the second block), plus layers of q² runs built from the q+1 mutually orthogonal directions of PG(1,q), plus one correction run.

**Run sizes**
- m = 0: 2q³ − 1
- m = 1: 2q³ − 1 + q²(q − 2)
- m ≥ 2: 2q³ + q²·max(q − 2, ⌈m(q − 2)/q⌉)

**Effect on the tables (Nov 2024 status in ColbournTables.md)**
60 entries are improved, for example:
- CA(324;3,32,5) instead of 349; CA(325;3,36,5) instead of 349; CA(350;3,37,5) instead of 365
- CA(930;3,58,7) instead of 979; CA(931;3,64,7) instead of 1014
- CA(3751;3,144,11) instead of 3971; CA(6253;3,196,13) instead of 6565
- q = 19: k = 382–401

There is no improvement for q = 3, 17 or 23.

**Testing**
- The tests use `caverify::ca_verify` like the other test files. Locally, I ran them with a brute-force stand-in for `ca_verify`, since I could not install the full dependency set: 40 expectations pass.
- All arrays were additionally checked by independent brute-force checkers (Python and C), including q = 7, 11, 13 and 19.
- `man/RMScopies.Rd` was generated by roxygen2 from the file alone. Please re-run `devtools::document()` if needed.
